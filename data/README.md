# Directorio de Datos (Local)

Este directorio está destinado a almacenar los archivos de datos crudos (`flota.*.csv`, `flota.*.xlsx`, etc.) para ejecución local.

> **⚠️ Nota de Seguridad y Privacidad:**
> Todos los archivos de datos en esta carpeta (excepto este archivo y `.gitkeep`) están excluidos del control de versiones (`.gitignore`) para garantizar la confidencialidad y protección de datos personales / corporativos.
> 
> Para pruebas automatizadas y desarrollo, consulte `tests/data/` y `data_test/`, que contienen datasets 100% sintéticos y seguros.
